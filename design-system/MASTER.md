# 拾光 1.1 · 桌面随手收藏

依据已安装 ui-ux-pro-max 的 Flat Design、Minimalism 与键盘可达性建议。生成器返回的营销页面结构与桌面工具不匹配，不采用该部分；以下布局为本项目设计。

最优先的是收存速度：主界面粘贴、文件拖入立即保存；不弹创建窗口，不要求标题或标签。全局快捷键同样直接收藏，不能打断正在编辑的收藏。输入框常驻，输入文字后 Enter 保存，Shift+Enter 换行，保留失败草稿。显示真实落盘状态，完成提示可撤销。

布局：浅灰白侧栏 + 冷白工作区 + 蓝色行动色；紧凑顶栏、内容卡片、底部常驻收存框。去掉大幅欢迎横幅、英文装饰段落及重复主按钮。标题/正文/附件/时间层级清晰。既有编辑窗仅用于后续整理。

颜色：背景 #F7F8FB、卡片 #FFFFFF、主文 #242B3D、次文 #667085、行动 #4263EB、浅行动底 #EEF2FF、侧栏 #FCFCFE、侧栏文字 #596579。各普通文本对比度 >=4.5；小图标按钮至少 28×28 CSS px。焦点可见，状态不依赖颜色；不以移动控件作为 hover 反馈。尊重 prefers-reduced-motion。

字体：系统 Segoe UI / Microsoft YaHei UI，正文 14px/1.7，标题 26px，辅助信息 12px。无需联网载入字体。图标为统一 24px viewBox 线条 SVG。品牌为蓝色双层折页便笺与光点，自有 SVG 源文件；同源高分辨率导出 Windows ICO 和托盘 PNG。

验证：940×640、1280×850、1440×900 桌面窗口；内容不被常驻收存框遮住。搜索框粘贴属于搜索，编辑窗粘贴属于编辑；输入法选字时 Enter 不发送。并发粘贴串行保存，失败保留文本或附件供重试。旧收藏时间与附件兼容。


1.2 修订：圆角焦点覆盖长文标题、正文、标签与搜索。原生 modal 配合根页面滚动锁及 overscroll containment；嵌套 modal 关闭前保留锁。非线性入场 360ms、退场 160ms，按钮回弹曲线，尊重减少动态效果。纯图片卡片完整 contain 等比缩小、最多 150px 高、不放大小图，底座仅一行时间和操作。点击缩略图直接打开查看器。迁移入口置于设置中的路径下方，迁移期间显示进度并禁止重复操作。


1.3：移除提示横幅，图片列表使用 600×300 上界的缓存缩略图且不放大小图，原图仅在查看器读取。卡片分批加载。弹窗遮罩独立且只用 opacity 合成；原生 ::backdrop 透明无 blur，面板仅 transform/opacity，阴影静态。初次登录采用轻量原生托盘入口，延迟 45 秒；闲置安全时退出完整程序，保留所有未发送草稿与失败队列。
